🟨 JS Mental Models Labs

Labs

Small, hands-on labs on how JavaScript actually behaves under the hood. Each lab is one mental model, one tiny experiment, one prediction before you run it. Concepts are ordered so nothing is used before it's explained — see CLAUDE.md in the repo for the full prerequisite graph and page-format spec.

Every lab below is tagged with its primary landmark from Class 2's recurring-concerns map — the same small set of questions every programming language has to answer somehow.
